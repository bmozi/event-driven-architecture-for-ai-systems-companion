# Architecting with Events in the Age of AI — Companion

Turn one important message into a defensible fact, then expose how its delivery,
retries, fan-out, cost, and automated reactions can multiply.

## The problem you may recognize first

You may have arrived because you need real-time integration, a streaming
platform, an event bus, or a way for agents to notice change. If reasonable
consumers infer different facts from the same message—or one stimulus can
produce more work and action than anyone can reconstruct—the problem is event
architecture before it is broker configuration.

This companion helps you produce a first reviewable result. It does not certify
an event contract, topology, organization, or AI reaction as safe, correct, or
ready for production.

## The book-and-companion contract

- **The book teaches the judgment:** what happened, who may declare it, what
  consumers may infer, how patterns change responsibility, and what evidence
  asynchronous systems require.
- **The companion provides the moves:** ontology records, pattern cards,
  multiplier tools, loop checks, failure matrices, and constructed examples.
- **The book stands alone:** this repository extends *Architecting with Events
  in the Age of AI* without reproducing its reasoning or narrative.
