# Role-Based Paths

Use one message that another party treats as important.

**Status:** Prepared development routes; representative-reader validation has
not occurred.

## Producer or consumer developer

1. Complete [Start Here](START-HERE.md).
2. Define the fact with the [Meaning-and-Authority Record](event-meaning-and-authority-record.md).
3. Record permitted inference and the invariant that survives duplicate,
   delay, disorder, and replay.
4. Run the [Failure Lab](FAILURE-LAB.md).

**Useful result:** A message contract whose meaning and failure behavior can be
implemented without relying on topic-name folklore.

## Architect or staff/principal engineer

1. Join meaning, causality, transformation, and reaction with the
   [Provenance Record](event-provenance-and-causality-record.md).
2. Calculate traffic, cost, and action growth with the
   [Multiplier Calculator](traffic-cost-action-multiplier-calculator.md).
3. Challenge replay, fan-out, capacity, and feedback paths.
4. Name where API capability, workflow responsibility, data fitness, or agent
   authority owns the neighboring decision.

**Useful result:** A defensible flow with bounded multiplication and explicit
domain handoffs.

## Engineering, product, service, or operations manager

1. Bring one consequential flow to the [Team Workshop](TEAM-WORKSHOP.md).
2. Use the [Value and Evidence Ledger](VALUE-AND-EVIDENCE-LEDGER.md).
3. Assign owners for meaning, publication, reactions, capacity, reconciliation,
   and stop paths.
4. Schedule a review using observed business outcomes, not message counts alone.

**Useful result:** Shared operational ownership for what one event can cause.

## CTO, CIO, business executive, or portfolio decision-maker

1. Use the [Executive Decision Brief](EXECUTIVE-DECISION-BRIEF.md).
2. Ask which responsiveness or partner capability the flow creates.
3. Review cost, autonomous-action growth, privacy, recovery, and evidence
   commitments.
4. Choose `EXPLORE`, `PROCEED BOUNDED`, `INVEST`, `HOLD`, or `STOP`.

**Useful result:** An investment boundary that does not confuse real-time
movement with trustworthy organizational awareness.

## Cross-role read-back

Ask someone outside the producer team to explain what happened, who may declare
it, what they may infer, which reactions are allowed, how they can multiply,
and which evidence closes the outcome. Record disagreement.
