# Practitioner Session Observation Rubric

<!-- markdownlint-disable MD013 -->

**Packet version:** `events-tools-blinded-v1-2026-08-29`

**Status:** Blank observer instrument; unexecuted

Record observable behavior and exact words. Do not diagnose the participant's
knowledge, intent, confidence, or competence.

## Observation codes

| Code | Observable behavior |
| --- | --- |
| C | Completed without a visible reread or request |
| R | Reread field or instruction before answering |
| Q | Asked what a field or instruction meant |
| S | Skipped or left blank |
| U | Explicitly marked unknown or requested missing information |
| I | Supplied implementation detail where the tool requested a decision |
| A | Added a scenario fact without marking it as an assumption |
| X | Answers conflict across the two tools |
| D | Revised an answer or decision after the challenge |
| N | Did not revise after the challenge |
| P | Facilitator provided a substantive prompt; protocol deviation |

Codes describe a moment, not a score. Add time and a short factual note.
